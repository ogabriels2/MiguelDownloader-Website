# Miguel Downloader website

Site oficial, bilíngue e estático do [Miguel Downloader](https://github.com/ogabriels2/MiguelDownloader),
publicado em <https://migueldownloader.ogabriels.com> pelo GitHub Pages.

- A publicação é validada e implantada automaticamente a cada mudança na `main`.
- Versão, downloads, tamanhos e SHA-256 são sincronizados com a release imutável mais recente.
- A fonte pública não usa rastreadores, telemetria, cookies nem processamento no servidor.
- Política de privacidade, suporte, licença e avisos de terceiros estão disponíveis em português e
  inglês.

Para a documentação de manutenção, consulte [LEIA-ME.md](LEIA-ME.md).
