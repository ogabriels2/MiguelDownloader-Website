Support

Official help for Miguel Downloader 1.0.0 and later

Found a problem? Start with the checks below. If it continues, send the app version, the site where it happened and the message shown — without passwords, cookies or other private data.

Before reporting

  1. Use the latest version. Installations from the website check GitHub for updates; Microsoft Store installations are updated by the Store itself.
  2. Make sure the link is public. The app does not circumvent private, subscriber-only or DRM-protected content.
  3. Try again a few minutes later. Platforms can temporarily limit connections or change their systems without notice.
  4. If the site requires a session, configure browser cookies. This option is off by default and sends cookies only to the matching site.

Diagnostic logs

The app keeps logs for seven days in %LOCALAPPDATA%\MiguelDownloader\logs. They may contain addresses you analysed. Review them before sharing and never post logs with private information in a public discussion.

Get help

Email
contato@ogabriels.com — use this channel when the report needs to mention a private address or include a reviewed log.
GitHub
Open a public issue for reproducible problems that contain no personal data.

Useful details to include

  • the Miguel Downloader version shown under Help › About;
  • your Windows version;
  • the source site and whether the content is public;
  • the steps that lead to the problem and the exact message shown;
  • whether another public link from the same site fails as well.

Privacy and security

Support will never ask for your password, authentication code or cookie file. Read the privacy policy, and get official versions only from the releases page.
